# Runtime Context Mechanics Rubric v1

This synthetic rubric admits deterministic mechanics only when protected loss,
unsupported facts, and silent truncation are zero; reference rehydration and
provenance accuracy and Evidence lineage coverage are 100%; and token reduction
is at least 25%.

It does not measure effective Evidence recall, downstream model quality,
end-to-end workflow quality, or real Candidate context. Effective Evidence
recall and workflow-completion degradation remain explicitly unmeasured until a
paired downstream consumption path exists. Passing is not a product-quality or
promotion claim.
